# IMovies - Movie Ticket Booking System

A full-stack MERN (MongoDB, Express.js, React.js, Node.js) web application designed to simplify movie ticket bookings with real-time seat selection and admin management controls.

## ?? Tech Stack
* **Frontend:** React.js, React Router, Bootstrap, Axios
* **Backend:** Node.js, Express.js, Mongoose ODM
* **Database:** MongoDB Atlas

## ? Key Features
* **User Authentication:** Secure signup and login with JWT and Bcrypt.
* **Movie Catalog:** Browse current movies, details, and showtimes.
* **Interactive Seat Selection:** Dynamic seat picking and booking confirmation.
* **User Booking History:** View past and active ticket reservations.
* **Admin Dashboard:** Complete management controls for movies, theaters, and show schedules.
